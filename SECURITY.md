# Security Policy

## Scope
This repository is a hobbyist trainer for **The Seven Deadly Sins: Origin**. It is
provided for educational reverse-engineering and single-player modding research.

## Supported versions
| Branch | Supported |
| ------ | --------- |
| main   | ✅        |
| 0.9.x  | ✅        |
| < 0.9  | ❌        |

## Reporting a vulnerability
Please **do not** open a public issue for anything that could be abused
against other players (e.g. RCE via a malicious profile, driver-bypass chains
that work in online co-op). Email the maintainers listed in `CODEOWNERS`
or DM `@sds-trainer` on the community Discord.

We will acknowledge within 72 hours and aim for a patch release inside 14 days.

## Out of scope
- Bans received for using the trainer online.
- Anti-cheat detection signatures.
- Issues requiring a specific GPU driver or Windows build.

## Warning
Using this software in online modes violates the Seven Deadly Sins: Origin
Terms of Service. The maintainers are not responsible for account bans,
hardware bans, or any damages. **Use at your own risk, offline only.**
